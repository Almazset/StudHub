# Проверка восстановления — 16.11.2026

Проверка выполнена в Windows PowerShell 5.1, Docker Desktop, PostgreSQL 16.
Java-код приложения не менялся; полный набор 101 теста прошёл на предыдущем
этапе. Для этих скриптов выполнены проверки, перечисленные ниже.

## Результат

- Создана реальная копия рабочей базы `studhub` в custom-формате pg_dump.
- Копия включает действующий ключ 2FA; проверено побайтовое совпадение с ключом приложения.
- NTFS ACL архива разрешает доступ текущему пользователю Windows и SYSTEM.
- Проверены SHA-256 дампа и ключа, полнота manifest и формат архива.
- Восстановление выполнено в новую отдельную базу PostgreSQL.
- При остановленных записях совпали данные всех **14 таблиц**, столбцы,
  последовательности, внешние/уникальные ключи и индексы.
- PostgreSQL после восстановления иначе записал приведения массивов в трёх CHECK.
  Условия эквивалентны. Дополнительно подтверждён отказ недопустимых значений
  роли пользователя и категории новости в восстановленной базе; транзакция отменена.
- StudHub запущен на восстановленной базе с `ddl-auto=validate` и ключом из архива.
  Страница `/login` вернула HTTP 200 на отдельном порту 18080. Приложение остановлено.
  Вход под реальным аккаунтом не выполнялся; чужие пароли не использовались.
- После усиления защиты временных файлов повторены копирование, восстановление
  и строгое сравнение: 14 таблиц совпали.

## Отказные сценарии

`tests/Test-RecoveryGuards.ps1` проверил:

1. Запрет перезаписи рабочей базы.
2. Отклонение опасного имени базы.
3. Запрет перезаписи уже существующей тестовой базы.
4. Отказ при повреждённом дампе.
5. Отказ при подмене ключа.
6. Отказ при отсутствии ключа.
7. Отказ при незавершённой копии без manifest.
8. Отказ при неверном формате архива даже с совпадающей контрольной суммой.
9. Неизменность списка баз и исходной копии после всех отказов.

Синтаксис PowerShell и `git diff --check` проверены. Сборку Java повторно не
выполняли: изменены только операционные скрипты, документация и .gitignore.

Архивы и подробные отчёты с контрольными суммами находятся вне Git,
в `%LOCALAPPDATA%\StudHub\backups`. Последняя проверенная копия:
`studhub-20261115T201017Z-d01d6d9c` (время в имени — UTC).
Её тестовая база: `studhub_restore_test_b0033aef24a7`.

Рабочая база не перезаписывалась, настройки подключения приложения не менялись.
Тестовый сервер остановлен. Копии сохранены; автоматическое расписание,
внешний носитель и внешняя зашифрованная копия пока не настроены.
