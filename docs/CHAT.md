# Чаты StudHub

Раздел `/chat`: личная переписка двух пользователей, группы до 30 участников и общий чат для всех вошедших в StudHub. Сообщения (до 4000 символов) и ссылки сохраняются в базе приложения. Обновление — каждые 4 секунды, только пока экран открыт. История загружается порциями по 50 сообщений. Непрочитанные отмечаются после открытия переписки.

Создатель группы может добавлять участников. При его выходе управление получает оставшийся участник с наименьшим ID. Вышедший участник теряет доступ к переписке; при повторном добавлении видит историю группы. В личном чате участвуют ровно два пользователя, повторное создание открывает существующую переписку.

Поиск по имени показывает только профили с видимостью «Участники StudHub». Скрытый профиль обозначается «Участник №ID», включая сообщения и список участников; email, фото и данные входа не возвращаются API чата. Чтобы другие могли найти вас по имени, измените видимость в настройках приватности. Доступ к сообщениям проверяется сервером при каждом запросе. Даже администратор не получает доступа к чужой личной переписке через API чата.

API `/api/chat`: `GET /rooms`, `GET /users?q=...`, `POST /direct` (`userId`), `POST /groups` (`name`, `userIds`), `GET /rooms/{id}`, `GET /rooms/{id}/messages?before=...` или `?after=...`, `POST /rooms/{id}/messages` (`text`, `clientId` UUID), `POST /rooms/{id}/read` (`messageId`), `POST /rooms/{id}/members` (`userIds`), `POST /rooms/{id}/leave`. Записи требуют сессии и CSRF. Повтор отправки с тем же clientId не создаёт дубликат. Ограничения: 30 сообщений в минуту на пользователя, 100 переписок на пользователя, до 30 участников группы.

В предпросмотре `docs/studhub-preview.html#chat` чаты демонстрационные: сохраняются только в этом браузере и не доставляются другим людям. Демонстрационные собеседники не отвечают автоматически. Настоящая переписка требует запущенного Spring-приложения, PostgreSQL и отдельных учётных записей.

Сообщения хранятся до удаления администратором базы; это не сквозное шифрование. Вложения и звонки не входят в эту версию. Для обмена материалами можно отправить текст или ссылку.
