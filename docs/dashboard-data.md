# Данные главной страницы

Главная использует AssignmentService: список заданий уже ограничен владельцем
в базе. Счётчики, процент выполнения, ближайшие сроки, календарь недели и
напоминания рассчитываются только по этому списку. Выполненные задания не
попадают в незавершённые сроки; просроченные остаются в начале списка.

Проекты выбираются через существующий ProjectRepository.visible: владелец или
участник проекта. В шаблон передаются только ID и название первых шести
доступных проектов; счётчик содержит полное число доступных проектов.
Исключённый участник после обновления главной больше не видит проект.

Курсы в текущей модели являются общедоступным каталогом: нет владельца,
приватности или записи на курс. Поэтому одинаковое число доступных курсов у
двух аккаунтов корректно. На главной это обозначено явно; первые шесть курсов
ведут на страницы каталога. Личные задания и прогресс курса не становятся общими.
При появлении приватных курсов нужно централизовать правила доступа к каталогу,
страницам и API; одной фильтрации главной для этого недостаточно.

Общее число пользователей больше не загружается в модель главной.

## Пустые состояния

- Нет заданий: объяснение, как начать, ссылки на курс и создание задания.
- Все задания выполнены: отдельное сообщение вместо приглашения начать с нуля.
- Нет проектов: предложение создать проект или получить приглашение.
- Нет курсов: объяснение и ссылка на создание первого курса.
