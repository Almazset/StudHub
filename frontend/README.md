# Frontend

Интерфейс StudHub хранится в стандартных папках приложения:

- `src/main/resources/static/css` — стили;
- `src/main/resources/static/js` — JavaScript;
- `src/main/resources/static/img` и `fonts` — ресурсы;
- `src/main/resources/templates` — HTML-шаблоны Thymeleaf;
- `docs/studhub-preview.html` — отдельный статический предпросмотр.

Здесь не размещается Java-код или настройки базы данных.
