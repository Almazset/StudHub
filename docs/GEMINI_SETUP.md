# Подключение учебного помощника StudHub

StudHub AI использует Google Gemini для работы с учебными материалами. Гид по сайту и сохранённые конспекты доступны в StudHub без ключа Gemini.

## 1. Получите ключ

Создайте ключ в [Google AI Studio](https://aistudio.google.com/apikey). Доступность модели и лимиты зависят от вашего проекта Google. Не отправляйте ключ в чат и не добавляйте его в HTML, JavaScript или Git.

## 2. Настройте сервер

Можно выбрать один из двух способов.

**Переменная окружения в PowerShell:**

```powershell
$env:GEMINI_API_KEY = "ВСТАВЬТЕ_СВОЙ_КЛЮЧ"
mvn.cmd spring-boot:run
```

**Локальный файл настройки:**

В корне проекта создайте папку `.studhub`, а в ней файл `ai.properties`:

```properties
studhub.ai.gemini-api-key=ВСТАВЬТЕ_СВОЙ_КЛЮЧ
```

Затем запустите приложение обычным способом. Папка `.studhub` исключена из Git, а сервер предпросмотра не раздаёт её содержимое. Файл содержит секрет: ограничьте доступ к нему на компьютере. Для опубликованного приложения используйте хранилище секретов или переменную окружения.

По умолчанию настроена `gemini-3.8-flash`. Для другой доступной модели задайте `GEMINI_MODEL` или свойство `studhub.ai.model`. Интеграция использует REST `generateContent` и `responseFormat` для структурированных ответов; при выборе другой модели проверьте поддержку этих параметров.

База PostgreSQL и вход в StudHub нужны, как при обычном запуске приложения. После настройки ключа перезапустите сервер.

## 3. Попробуйте лекцию

1. Войдите в StudHub на http://localhost:8080 и откройте **StudHub AI**.
2. Выберите режим, прикрепите лекции или вставьте текст. Для плана подготовки укажите дату экзамена, темы и доступное время. Для помощи с задачей добавьте свою попытку или текст ошибки.
3. При отправке файлов подтвердите передачу материалов в Google Gemini. Пока запрос выполняется, помощник показывает состояние и даёт остановить ожидание.
4. Конспект с ключевыми терминами можно сохранить в StudHub и открыть позже. Карточки показывают ответ по запросу. В тесте сначала выберите ответы, затем проверьте результат и объяснения.
5. Кнопка создания задания из ответа открывает обычную форму с черновиком. Отредактируйте его, укажите срок и нажмите **Сохранить**, если хотите создать задание.

Для проверки можно использовать безопасные примеры в разных форматах. Например, объедините файл [lecture-java.txt](examples/lecture-java.txt) с собственными тестовыми PDF и DOCX и попросите перечислить темы каждого документа по отдельности.

## Форматы и ограничения

- PDF, DOCX, PPTX, TXT, MD, JPG, JPEG и PNG.
- До трёх файлов, до 8 МБ каждый, до 12 МБ суммарно.
- Из DOCX и PPTX извлекается текст. Для анализа схем, таблиц и иллюстраций сохраните материал в PDF или загрузите изображение.
- Для текстовых материалов предел — 120 000 символов на запрос. Большую лекцию разделите на части.
- Ответ содержит не более пяти карточек заданий. Создание записей в учебном плане требует отдельного сохранения пользователем.

## Что отправляется в Google

Google Gemini получает введённый текст и до восьми предыдущих реплик этого чата. После подтверждения отправки файлов сервис также получает PDF и изображения в исходном виде, а из DOCX, PPTX, TXT и MD — текст. Данные профиля, курсы, задачи и сроки StudHub автоматически в запрос не включаются.

Переписка и прикреплённые лекции хранятся в открытой вкладке. При повторной отправке с прикреплёнными файлами Gemini снова получает материалы. В PostgreSQL сохраняются только конспекты, которые пользователь решил сохранить. Каждый конспект доступен только своему владельцу и может быть удалён. Для обработки загрузки сервер может использовать временные файлы, которые удаляются после запроса.

Запросы задают `store: false`; обработка данных Google всё равно определяется условиями и настройками вашего проекта Gemini. Статус этой настройки не является обещанием отсутствия всех журналов у провайдера.

## Защита и ошибки

API требует входа в аккаунт и CSRF. Файлы проверяются на сервере: формат, размер, размеры изображений, XML-сущности и объём распакованного архива. Модель не получает инструменты для изменения сайта. Её ответы отображаются как текст; адреса и команды из ответов не исполняются.

Один аккаунт может выполнять один запрос за раз, до восьми запросов в минуту и сорока в сутки; одновременно сервер обрабатывает до четырёх запросов. Ограничения хранятся в памяти одного экземпляра приложения и сбрасываются при перезапуске. Для нескольких экземпляров и устойчивого учёта расходов потребуется общее хранилище лимитов и квоты проекта Google.

Ожидание ответа ограничено. Кнопка остановки прекращает ожидание в браузере и скрывает последующий ответ; она не гарантирует отмену обработки или списания у провайдера. Повтор выполняется только по действию пользователя.

Если ключ отсутствует, помощник сообщает об этом и не отправляет материалы. Сообщения об ошибках различают недоступную модель, проблему с ключом, исчерпанную квоту, блокировку ответа и слишком долгое ожидание. Предпросмотр на порту 8765 показывает интерфейс, выбор файлов и работающий гид. Для ответов Gemini используйте запущенное приложение на порту 8080.

## Проверка интеграции

`mvn.cmd test` проверяет чтение лекций, защиту API, ограничения и обработку структурированных ответов с имитацией Gemini. Проверка нескольких файлов включает оба пути передачи: извлечённый текст и двоичные вложения. Для проверки настоящей модели настройте GEMINI_API_KEY в окружении PowerShell и запустите:

    $env:STUDHUB_RUN_GEMINI_LIVE = '1'
    mvn.cmd '-Dtest=GeminiClientTest#realGeminiReadsSyntheticLecturesInEverySupportedFormat' test
    Remove-Item Env:STUDHUB_RUN_GEMINI_LIVE

Эта проверка делает три запроса к Gemini с созданными тестом лекциями и изображениями. Она использует квоту вашего проекта Google.

Официальные источники: [генерация ответа](https://ai.google.dev/api/generate-content), [обработка документов](https://ai.google.dev/gemini-api/docs/document-processing), [Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash).
