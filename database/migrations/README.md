# Архив ручных миграций

Файлы V001–V011 использовались для обновления StudHub до подключения Flyway. Они нужны для [перехода существующей базы](../README.md#переход-существующей-базы-на-flyway), если часть этих изменений ещё не применена.

Flyway читает каталог [src/main/resources/db/migration](../../src/main/resources/db/migration). В нём находится полная схема V011 для чистой установки. Следующее изменение схемы добавляйте отдельным файлом `V012__short_description.sql`, последующие версии используйте по порядку. Уже применённые файлы сохраняйте без изменений, чтобы Flyway мог проверить их контрольные суммы.
