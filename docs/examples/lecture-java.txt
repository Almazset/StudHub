Лекция: коллекции в Java

Коллекции хранят группы объектов. Интерфейс List описывает упорядоченную последовательность и допускает повторяющиеся элементы. Set представляет множество уникальных элементов. Map хранит пары ключ–значение и не наследует интерфейс Collection.

ArrayList обычно удобен для доступа к элементу по индексу и добавления в конец. Вставка в середину требует сдвига элементов. HashSet помогает проверять уникальность, а HashMap — находить значение по ключу.

Пример: список покупок можно хранить в ArrayList, уникальные теги — в HashSet, а соответствие идентификатора студента его имени — в HashMap.

При выборе структуры учитывают порядок элементов, необходимость повторов, доступ по индексу или ключу и частоту изменений. Для объектов в хеш-коллекциях важно согласованно определять equals и hashCode.
